# Қаржылық сауаттылық · qarjy.

Қазақша, орысша және ағылшынша жеке қаржыны бақылауға арналған веб-қосымша. Қолданыстағы Next.js жобасының негізінде жасалған.

## Технологиялар

- Next.js **16.4.2**, App Router
- React **19.3.0**, TypeScript **5**
- Tailwind CSS **4**, қолданыстағы `@tailwindcss/turbopack` интеграциясы
- `localStorage` және серверлік JSON-файл: шоттар, санаттар, транзакциялар, жинақ мақсаттары, бюджет, сабақ прогресі және түс режимі
- Қосымша UI кітапханалары мен сыртқы қаржы API-лері қажет емес

## Іске қосу

Node.js 20.9 немесе одан жаңа нұсқасы қажет. Тексеру сценарийіне Node.js 22.18+ немесе 24+ ұсынылады.

```powershell
cd C:\Users\Acer\My-project\financial-literacy
npm install
npm run dev
```

Тәуелділіктер орнатылған болса, `npm install` қадамын өткізіңіз. Браузерде [http://localhost:3000](http://localhost:3000) ашыңыз. Порт бос болмаса: `npm run dev -- --port 3001`.

Өндірістік нұсқаны құру және іске қосу:

```powershell
npm run build
npm run start
```

## Бөлімдер

| Мекенжай | Мүмкіндіктер |
| --- | --- |
| `/` | Қаржылық сауаттылық туралы ақпарат, жалпы көрсеткіштер, алғашқы қадамдар |
| `/dashboard` | Жалпы баланс, кіріс, шығыс, соңғы алты ай диаграммасы, шығыс санаттары және мақсаттар |
| `/transactions` | Қосу, өңдеу, растаумен өшіру, іздеу, шот пен санат бойынша сүзу және CSV экспорт |

| `/categories` | Кіріс пен шығыс санаттарын қосу, көру, өңдеу және растаумен өшіру |

Жарық/қараңғы режим жоғарғы панельдегі батырмамен ауысады. Алғаш кіргенде құрылғының түс таңдауы ескеріледі. Интерфейс телефонға бейімделген; мобильді мәзір жоғарғы сол жақтағы батырмамен ашылады.

Тіл жоғарғы панельдегі **Қазақша / Русский / English** таңдағышымен ауысады. Таңдау `qarjy.locale.v1` кілтінде сақталады. Күн, ақша және бастапқы санаттар таңдалған тілде көрсетіледі. Өзіңіз енгізген атаулар мен сипаттамалар өзгермейді.

## Деректер және есептеу

- Қаржы деректері **сервердегі `data/finance.json` файлына** және осы браузердің `localStorage` жадындағы `qarjy.finance.v1` кілтіне сақталады. API қолжетімді болса, сервер нұсқасы жүктеліп, браузерге көшіріледі.
- Backend-ті ашу үшін серверге кемінде 32 таңбалы `FINANCE_API_KEY` орта айнымалысын орнатыңыз. Ол ортақ кіру құпиясөзі ретінде қолданылады; кодқа немесе Git-ке қоспаңыз. Кіру сессиясы HttpOnly cookie арқылы 24 сағатқа беріледі. Кіру және шығу: `/api/auth/login`, `/api/auth/logout`.
- Бұрынғы `version: 1` жазбалары оқылғанда теңгелік «Негізгі шотқа» байланысады. Транзакциялар мен мақсаттардың ID-лері, сомалары, мерзімдері, бюджет, тақырып және сабақ прогресі сақталады. Алғашқы сәтті өзгерісте жаңартылған JSON жазылады.
- Серверлік деректер оқылмайтын немесе API қолжетімсіз болса, қосымша браузердегі localStorage дерегін пайдаланады. `serverUnavailable` ескертуі пайда болғанда деректер тек ағымдағы браузерде сақталуы мүмкін.
- Алғашқы іске қосуда есеп бос болады: үлгі транзакциялар шынайы дерек ретінде қосылмайды.
- Ақша валютаның жүздік бірлігімен бүтін сан ретінде сақталады. Мысалы, `1250.50` және `1250,50` бір мәнге айналады. Теріс енгізулерге және екіден артық ондық таңбаға рұқсат жоқ.
- Ағымдағы баланс = бастапқы баланс + кіріс − шығыс. Dashboard әр валютаны бөлек есептейді. Калькуляторға осы айдың теңгелік транзакциялары алынады.
- Транзакциясы бар шотты немесе санатты өшіру үшін байланысты жазбаларды басқа шотқа немесе санатқа ауыстырыңыз. Байланыс сақталып тұрғанда шот валютасы мен санат түрі өзгертілмейді.
- Жинақ мақсаттары — бөлек есеп. Толықтыру балансқа әсер етпейді, банк шотына ақша аудармайды. Мақсат сомасынан артық толықтыруға болмайды.
- Калькулятор нәтижесі өрістер өзгергенде қайта есептеледі; «Есептеу және сақтау» жоспарын сақтайды. 50/30/20 — міндетті норма емес, жоспарлау үлгісі.
- Сабақ дұрыс тест жауабы таңдалған соң аяқталады. Қосымша оқу көзі: [Fingramota.kz](https://fingramota.kz/index.php/kk).
- Жарамсыз JSON үстінен жазылмайды. Оқу немесе сақтау сәтсіз болса, интерфейс ескерту көрсетеді. `localStorage` жергілікті есепке арналған және қорғалған серверлік сақтаудың баламасы емес.

Автоматты тесттер ақша дәлдігін, балансты, мақсат прогресін, сақталған деректерді, үш тілдегі мәтіндер мен параметрлердің толықтығын, санатпен іздеуді және сабақ тесттерінің сәйкестігін тексереді.

Қолмен тексеру: транзакция қосып/жойып, Dashboard көрсеткіштерін салыстырыңыз; бетті жаңартып деректі тексеріңіз; мақсат құрып, толықтырып, прогресті бақылаңыз; калькуляторда кірістен артық шығыс енгізіңіз; сабақ тестін аяқтаңыз; режимді ауыстырып, телефон өлшемінде мәзірді тексеріңіз.

## Next.js интерфейсі және функциялар (2026-11-03)

Барлық дизайн мен әрекет негізгі Next.js App Router беттеріне біріктірілген.
Басты бетте нақты кіріс/шығыс, соңғы транзакциялар және жинақ мақсаттары көрінеді.
Басты бет, Dashboard және транзакциялар бөлімі ортақ React/TypeScript формасымен
транзакция қосады және өңдейді. Өзгерістер localStorage-ға сақталып, барлық бөлімде жаңарады.
Кіріс/шығыс іздеуі, ай/санат сүзгілері, күн/сома сұрыптауы және CSV экспорты бар.

Телефонда төменгі навигация және пернетақтамен басқарылатын толық мәзір қолданылады.
Бөлек HTML макет пен үлгі транзакциялар қолданылмайды.
Функциялардың түсіндірмесі: [docs/JS-FUNCTIONS.md](docs/JS-FUNCTIONS.md).

Іске қосу: npm run dev. Порт бос болмаса: npm run dev -- --port 3011.

Қорытынды тексеру нәтижелері: [docs/VERIFICATION.md](docs/VERIFICATION.md).

## HTTP IP мекенжайы арқылы ашу

Жергілікті желідегі тексерілген мекенжай: `http://192.168.56.1:3011/`.
Осы хост Next.js `allowedDevOrigins` тізімінде көрсетілген.
Жазба ID-ін жасайтын `lib/record-id.ts` HTTP ортасында `crypto.randomUUID`
қолжетімсіз болса да транзакция мен мақсат қосуды қамтамасыз етеді.

`localhost`, `127.0.0.1` және `192.168.56.1` браузер үшін бөлек origin болып саналады:
әрқайсысының localStorage деректері бөлек. Бұрынғы жазбалар өз мекенжайында сақталады.
Жоба жаңартылғаннан кейін бетті `Ctrl+F5` арқылы қайта жүктеуге болады.
