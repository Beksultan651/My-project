# Қаржылық сауаттылық · qarjy.

Қазақша, орысша және ағылшынша жеке қаржыны бақылауға арналған веб-қосымша. Қолданыстағы Next.js жобасының негізінде жасалған.

## Технологиялар

- Next.js **16.4.2**, App Router
- React **19.3.0**, TypeScript **5**
- Tailwind CSS **4**, қолданыстағы `@tailwindcss/turbopack` интеграциясы
- `PostgreSQL` және Prisma ORM 7: шоттар, санаттар, транзакциялар, жинақ мақсаттары, бюджет, сабақ прогресі және түс режимі
- Қосымша UI кітапханалары мен сыртқы қаржы API-лері қажет емес

## Іске қосу

Node.js 24 қажет.

```powershell
cd C:\Users\Acer\My-project\financial-literacy
npm install
if (!(Test-Path .env.local)) { Copy-Item .env.example .env.local }
# .env.local ішіндегі DATABASE_URL мәнін толтырыңыз.
npm run db:migrate
npm run dev
```

Тәуелділіктер орнатылған болса, `npm install` қадамын өткізіңіз. `.env.local` бұрыннан бар болса, оған тек `DATABASE_URL` жолын қосыңыз. Браузерде [http://localhost:3000](http://localhost:3000) ашыңыз. Порт бос болмаса: `npm run dev -- --port 3001`.

Өндірістік нұсқаны құру және іске қосу:

```powershell
npm run build
npm run start
```

Тіл жоғарғы панельдегі **Қазақша / Русский / English** таңдағышымен ауысады. Таңдау `qarjy.locale.v1` кілтінде сақталады. Күн, ақша және бастапқы санаттар таңдалған тілде көрсетіледі. Өзіңіз енгізген атаулар мен сипаттамалар өзгермейді.

## Деректер және есептеу

- Node.js 24 қолданыңыз. Тіркелу, кіру және шығу әрекеттері `/api/auth/register`, `/api/auth/login` және `/api/auth/logout` арқылы орындалады.
- Әр аккаунттың қаржы деректері сервердегі PostgreSQL базасында сақталады. Құпиясөзге жеке тұзымен scrypt қолданылады. Сессия cookie арқылы беріледі және 24 сағатқа жарамды.
- Бос аккаунтта «Бұрынғы деректерді көшіру» бөлімінен осы браузердегі жазбаларды көшіре аласыз. Ескі сервер файлын көшіру үшін сервердегі бұрынғы `FINANCE_API_KEY` және сол құпиясөз қажет. Ескі сервер дерегі бір аккаунтқа көшіріледі; бастапқы файл сақталады.
- Транзакция, шот, санат, мақсат және бюджет аккаунтқа байланыстырылған. Ақша сомалары бүтін тиын ретінде PostgreSQL BigInt өрісінде сақталады.
- Алғашқы іске қосуда есеп бос болады: үлгі транзакциялар шынайы дерек ретінде қосылмайды.
- Ақша валютаның жүздік бірлігімен бүтін сан ретінде сақталады. Мысалы, `1250.50` және `1250,50` бір мәнге айналады. Теріс енгізулерге және екіден артық ондық таңбаға рұқсат жоқ.
- Ағымдағы баланс = бастапқы баланс + кіріс − шығыс. Dashboard әр валютаны бөлек есептейді. Калькуляторға осы айдың теңгелік транзакциялары алынады.
- Транзакциясы бар шотты немесе санатты өшіру үшін байланысты жазбаларды басқа шотқа немесе санатқа ауыстырыңыз. Байланыс сақталып тұрғанда шот валютасы мен санат түрі өзгертілмейді.
- Жинақ мақсаттары — бөлек есеп. Толықтыру балансқа әсер етпейді, банк шотына ақша аудармайды. Мақсат сомасынан артық толықтыруға болмайды.
- Калькулятор нәтижесі өрістер өзгергенде қайта есептеледі; «Есептеу және сақтау» жоспарын сақтайды. 50/30/20 — міндетті норма емес, жоспарлау үлгісі.
- Сабақ дұрыс тест жауабы таңдалған соң аяқталады. Қосымша оқу көзі: [Fingramota.kz](https://fingramota.kz/index.php/kk).
- Жарамсыз JSON үстінен жазылмайды. Оқу немесе сақтау сәтсіз болса, интерфейс ескерту көрсетеді. `localStorage` жергілікті есепке арналған және қорғалған серверлік сақтаудың баламасы емес.

## HTTP IP мекенжайы арқылы ашу

Жергілікті желідегі тексерілген мекенжай: `http://192.168.56.1:3011/`.
Осы хост Next.js `allowedDevOrigins` тізімінде көрсетілген.
Жазба ID-ін жасайтын `lib/record-id.ts` HTTP ортасында `crypto.randomUUID`
қолжетімсіз болса да транзакция мен мақсат қосуды қамтамасыз етеді.

`localhost`, `127.0.0.1` және `192.168.56.1` браузер үшін бөлек origin болып саналады:
әрқайсысының localStorage деректері бөлек. Бұрынғы жазбалар өз мекенжайында сақталады.
Жоба жаңартылғаннан кейін бетті `Ctrl+F5` арқылы қайта жүктеуге болады.

## PostgreSQL дерекқоры

Жоба [Prisma ORM 7](https://www.prisma.io/docs/orm/v7) және Node.js 24 қолданады. Бос PostgreSQL дерекқорын дайындап, байланыс жолын жергілікті `.env.local` файлына немесе хостингтің орта айнымалысына `DATABASE_URL` ретінде енгізіңіз. Құпиясөзді кодқа, Git-ке немесе чатқа салмаңыз. Басқарылатын PostgreSQL үшін сервер талап ететін TLS параметрлері бар қосылым жолын қолданыңыз.

```powershell
npm run db:generate
npm run db:migrate
npm run dev
```

Migration командасы соңғы схеманы қолданады. Жоба іске қосылғанда Prisma схеманы өздігінен өзгертпейді. HTTPS проксиінің артында `QARJY_ORIGIN` мәніне сайттың толық HTTPS мекенжайын қойыңыз.

Егер бұрынғы SQLite базасы бар болса, қолданбаны іске қоспай тұрып оны PostgreSQL-ға көшіріңіз. Бастапқы SQLite файлын сақтық көшірмелеңіз. Импорт бос PostgreSQL дерекқорында бір транзакциямен орындалады, бұрынғы файл тек оқу режимінде ашылады. Пайдаланушылар бұрынғы атымен және құпиясөзімен қайта кіре алады.

```powershell
npm run db:import-sqlite -- data/qarjy.sqlite
```

Бұрынғы ортақ JSON файлы сайттағы «Бұрынғы деректерді көшіру» бөлімінен бұрынғы ортақ құпиясөз арқылы көшіріледі. Файл әдетте `data/finance.json` мекенжайында. Басқа жолды `QARJY_LEGACY_PATH` арқылы беріңіз. Постгрес импорты бұрын көшірілген ортақ JSON-ның екінші рет алынуына жол бермейді.

Нақты PostgreSQL интеграция тесті үшін migration қолданылған, пайдаланушы деректері жоқ жеке сынақ базасын пайдаланыңыз. `TEST_DATABASE_URL` орта айнымалысын сол базаға байланыстырған соң `npm run db:generate` және `npm run test:db` орындаңыз. Қалған автоматты тесттер `npm test` арқылы іске қосылады.

## Әкімші және пайдаланушы кабинеті

Мәзірден «Оқу кабинеті» бөлімін ашыңыз. Пайдаланушы «Шолу» бөлімінде әкімшіні таңдап, қаржылық деректерін көруге рұқсат береді. Рұқсатты қайтарғанда әкімшінің осы пайдаланушыға қатынасы жабылады. Қолданыстағы аккаунттар бастапқыда ешбір әкімшіге бекітілмейді.

Әкімші пайдаланушыны таңдап виртуалды теңге бөледі. Бұл сома оқу кабинетінің бөлу тарихында сақталады. Виртуалды қалдық бөлінген сомадан пайдаланушы енгізген KZT шығындарын шегеру арқылы есептеледі. Кәдімгі шоттың бастапқы балансы мен басқа валютадағы жазбалар бұл есепке қосылмайды. Белсенді пайдаланушы көрсеткіші кемінде бір мерзімі өтпеген сессиясы бар рұқсат берген аккаунттарды санайды.

«Хабарламалар» бөлімінде әкімші кеңес жіберіп, пайдаланушы жауап береді. Ашық кабинет хабарламаларды 30 секунд сайын жаңартады. «Есептер» жеке және сүзгіленген жалпы CSV шығарады. Аудит журналы AdminEvent кестесінде сақталады.

Жаңа API тестін іске қосу үшін бөлек сынақ базасын дайындап, оған миграцияны қолданыңыз. Жергілікті сынақ серверін сол базамен іске қосыңыз. TEST_DATABASE_URL мәнін осы базаға, TEST_APP_ORIGIN мәнін сервердің http://127.0.0.1 мекенжайына портымен бірге қойып, node --test tests/supervision-api.test.mjs орындаңыз.
