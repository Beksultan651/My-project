# Негізгі Next.js сайтының тексеру нәтижесі

Күні: 2026-11-03. Жоба: `C:\Users\Acer\My-project\financial-literacy`.

Дизайн және функциялар негізгі App Router беттеріне біріктірілді. Бөлек HTML/CSS/JS макет файлдары мен сілтемелері жойылды.

## Автоматты тексеру

- Next.js production build және оның TypeScript тексеруі: сәтті.
- ESLint: қате және ескерту жоқ.
- Node test: 19 тест сәтті өтті. Ақша дәлдігі, күндер, localStorage валидациясы, баланс, мақсат прогресі, сүзгілер/сұрыптау, HTTP ортасындағы ID, үш тілдегі мәтіндер мен параметрлердің толықтығы, аударылған санатпен іздеу және сабақ тесттерінің сәйкестігі тексерілді.

## Браузерде тексерілгені

- Басты бет пен Dashboard-тан ортақ React/TypeScript транзакция формасы ашылады.
- Басты беттен транзакция қосу және өңдеу. Өңдегенде ID сақталады, көшірме қосылмайды.
- Бет жаңарғаннан кейін өзгерген сома localStorage арқылы қалпына келеді.
- Dashboard пен басты бет бірдей балансты көрсетеді: сынақта 12 000,25 ₸ кіріс және 3 000,40 ₸ шығыс → 8 999,85 ₸ баланс.
- Сома бойынша сұрыптау, санат сүзгісі және түр/санат сүзгілерін бірге қолдану.
- Мақсат құру және оның 20% прогресін басты бетте көрсету.
- Растаумен транзакция/мақсат жою. Тек QA үшін қосылған 3 транзакция мен 1 мақсат тазартылды.
- Мобильді төменгі навигация; мәзірде Tab/Shift+Tab айналымы, Escape; модаль жабылғанда фокусты батырмаға қайтару.
- Қараңғы/жарық режимі және қазақша ай атаулары.
- `/`, `/dashboard`, `/transactions`, `/calculator`, `/goals`, `/learn` беттері 390×844, 768×1024, 1440×1000 өлшемдерінде тексерілді: **18 тексеру, көлденең тасу жоқ**.
- Негізгі сайттың браузер консолінде error деңгейіндегі хабарлама жоқ.

## 192.168.56.1:3011 мекенжайындағы HTTP түзетуі

- Next.js dev ресурстарының осы хост үшін бұғатталғаны сервер журналынан анықталды. `allowedDevOrigins` тізіміне тек `192.168.56.1` қосылды.
- «Сақтау» әрекеті кезінде `TypeError: crypto.randomUUID is not a function` қатесі браузерде қайталанды.
- Транзакция мен мақсат ортақ `createRecordId()` функциясын қолданады. Ол native UUID, HTTP-де қолжетімді random bytes немесе жергілікті балама жолды таңдайды. Бұл ID авторизация құпиясы емес.
- Дәл `http://192.168.56.1:3011/dashboard` арқылы транзакция қосылды, 123,45 ₸ → 200,55 ₸ болып өңделді. Бет жаңарғаннан кейін сома сақталды, көшірме қосылмады.
- Осы IP арқылы мақсат құрылды, бет жаңартылып сақталуы тексерілді, 500 / 1 000 ₸ толықтыруы 50% прогресс көрсетті.
- Түзетуден кейін жаңа браузер қатесі тіркелмеді. QA үшін қосылған 1 транзакция мен 1 мақсат тазартылды.
- IP арқылы жүктелетін 16 Next.js script жауабы: HTTP 200.

## Үш тілдегі интерфейс

- Қазақша, орысша және ағылшынша таңдау барлық бөлімде жұмыс істейді. `qarjy.locale.v1` жеке кілті қолданылады; қаржы деректерінің схемасы өзгермеді.
- Мәзір, бет атаулары, формалар, күндер, санаттар, ақша пішімі, хабарламалар, алты сабақ және тест жауаптары аударылды. HTML `lang`, бет тақырыбы және meta description таңдалған тілге сәйкес жаңарады.
- `http://192.168.56.1:3011/` арқылы тіл ауыстыру, бөлімдер арасында өту және бетті жаңартқаннан кейін тілдің қалпына келуі тексерілді.
- Орысша 1 234,56 ₸ шығыс қосылды, ағылшынша санат іздеу арқылы табылды, 1,234.57 ₸ болып өңделді және қайта жүктегенде сақталды. Енгізілген қазақша атау өзгерген жоқ. Сынақ жазбасы қазақша интерфейсте жойылды.
- Орысша мақсат құрылды: 100 / 1 000 ₸. 900 ₸ қалдықтан артық толықтыруға аударылған қате хабарламасы берілді. 150 ₸ толықтырылғаннан кейін ағылшынша 250 / 1,000 ₸ және 25% көрінді. Тек осы сынақ мақсаты тазартылды.
- Орысша және ағылшынша сабақ мазмұны, қате/дұрыс тест жауабы және аяқтау батырмасының күйі тексерілді. Пайдаланушының оқу прогресі өзгертілмеді.
- Алты бет × үш тіл 390×844 өлшемінде, алты орысша бет 1440×1000 және алты ағылшынша бет 768×1024 өлшемінде тексерілді. Барлығы **30 бет/тіл/өлшем тексеруі**; толық жүктелген беттерде көлденең тасу жоқ.
- Телефондағы тіл таңдағышы көрінеді және жеткілікті биіктігі бар. Қараңғы режим сақталды.
- Интерфейстегі артық техникалық және қайталанатын сипаттамалар қысқартылды. Көрінетін UI мәтінінде AI/ИИ/ЖИ, ChatGPT, Codex немесе OpenAI туралы сипаттама жоқ.
