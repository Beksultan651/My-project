# Next.js сайтындағы интерактивті функциялар

Дизайн қолданыстағы Next.js App Router жобасына енгізілген. React Client Components,
TypeScript, Tailwind CSS және localStorage қолданылады. Бөлек HTML макет жоқ.

| Бет/компонент | Қызметі |
| --- | --- |
| app/page.tsx | Басты бет: нақты баланс, соңғы транзакциялар, мақсаттар, оқу қадамдары. Қосу/өңдеу формасын тікелей ашады. |
| components/transaction-dialog.tsx | Басты бет, Dashboard және транзакциялар бөліміне ортақ форма. Кіріс/шығыс қосу, өңдеу, сома/күн валидациясы. |
| app/transactions/page.tsx | Іздеу, ай/түр/санат сүзгілері, сұрыптау, растаумен жою және CSV жүктеу. |
| lib/transactions.ts · filterTransactions() | Сүзгілерді бірге қолданады, күн/сомамен сұрыптайды. Бастапқы массив өзгермейді. |
| app/dashboard/page.tsx | Нақты көрсеткіштер, 6 ай диаграммасы, шығыс санаттары; ортақ формамен қосу/өңдеу. |
| app/calculator/page.tsx | Кіріс пен шығысты есептеу, жоспар сақтау, осы айдың транзакцияларынан алу. |
| app/goals/page.tsx | Мақсат құру, толықтыру, прогресс және растаумен жою. |
| app/learn/page.tsx | 6 қысқаша сабақ, шағын тест және аяқталу прогресі. |
| components/finance-provider.tsx | Ортақ күй, localStorage және бір origin-дегі қойындылар арасында синхрондау. |
| components/app-shell.tsx | Төменгі мобильді навигация, қараңғы/жарық режим; мәзірдегі фокус, Tab және Escape. |

Форма useState арқылы мәндерді ұстайды. onClick, onChange, onSubmit әрекеттері
React ішінде орындалады. Қолданыстағы жазба өңделсе, ID сақталады және көшірме қосылмайды.
Басқа қойындыда жойылған жазбаны сақтау әрекеті қате көрсетеді.

Басты бет пен Dashboard бір дереккөзді қолданады. Алғашқы іске қосуда барлық есеп бос;
үлгі қаржы деректері шынайы балансқа қосылмайды. Бұрынғы qarjy.finance.v1 сақтау схемасы сақталған.

Тексеру: npm run lint; npx tsc --noEmit; node --test tests/finance.test.mjs; npm run build.
